# Security policy

ParallelEarth 0.1 is a local development release. Worktrees are not security sandboxes. Use trusted repositories and review scripts.

Report vulnerabilities privately through a verified maintainer contact once a public repository is configured. No private reporting endpoint is currently verified; do not post credentials publicly. Include versions, reproduction steps, expected boundary and observed impact. Approval bypass, traversal, unsafe cleanup and inaccurate verification are in scope. Arbitrary behavior of explicitly approved code is a documented boundary.

See docs/security-model.md and docs/validation.md.
